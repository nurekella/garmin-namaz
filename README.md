# Namaz KZ — Garmin Connect IQ

Время намаза для часов Garmin по методике **ҚМДБ (ДУМК)**.
Работает оффлайн по GPS, уведомляет вибрацией, показывает дату по хиджре.

Языки: **қазақша / русский / english** (по системному языку часов или вручную).

## Возможности (v1.7)

- 5 намазов + восход + тахажжуд (последняя треть ночи по завтрашнему Фаджру)
- Карточный интерфейс: обзор дня, обратный отсчёт, 7-дневный календарь,
  карточка на каждый намаз, прогресс-бар дня
- Glance-виджет: следующий намаз, время и сколько осталось
- Вибрация в момент намаза, 4 паттерна, усиленный паттерн на жума,
  предуведомление отдельно для Фаджра и остальных намазов
- 10 методов расчёта (ҚМДБ, MWL, Diyanet, Egyptian, ISNA, Karachi, Jafari,
  Umm al-Qura, Tehran, Fixed Isha); Аср Ханафи / стандарт
- Umm al-Qura: Иша 120 мин после Магриба в Рамадан, 90 мин в остальное время
- Кибла-компас
- Ручной выбор города из 16 областных центров + Auto (GPS)
- Per-prayer offset ±9 мин
- 4 цветовые темы под true-black AMOLED
- Часовой пояс берётся из часов (с учётом DST), работает за пределами Казахстана

## Точность (методика ҚМДБ)

Модель восстановлена по полному календарю 2026 года с
[api.muftyat.kz](https://api.muftyat.kz/prayer-times/) для всех 16 областных
центров и ~40 малых населённых пунктов:

| Параметр | Значение |
|---|---|
| Фаджр / Иша | солнце 15° под горизонтом |
| Восход / закат | 0.833° |
| Высокие широты | angle-based (сумерки ≤ 15/60 ночи) |
| Ихтият, широта < 48° | Зухр, Аср, Магриб +3 мин; восход −3 мин |
| Ихтият, широта ≥ 48° | Зухр, Аср, Магриб +5 мин; восход −5 мин |
| Аср | Ханафи (тень = 2 высоты) |

Положение солнца считается на момент каждого намаза, а не на полдень.
Расхождение с muftyat.kz по всем городам за весь 2026 год: **≤ 1 минуты**
(в пределах их округления до минуты). Тесты закрепляют 4 даты для Алматы,
Астаны, Шымкента и Петропавловска.

Дата по хиджре: таблица Umm al-Qura на 1440–1470 гг. (сентябрь 2018 —
июнь 2049), совпадает с muftyat.kz день в день. Вне диапазона используется
табличный алгоритм (±1 день).

## Целевые устройства

- **Главное:** Garmin Epix Gen 2 (416×416 AMOLED, круглый)
- В манифесте: Epix 2 Pro, Fenix 7 / 7 Pro / 8, Forerunner 165 / 265 / 955 / 965 / 970,
  Enduro 3, MARQ Gen 2, Venu 3 / Sq 2 / 4

## Установка SDK (для разработки)

1. Скачайте **Connect IQ SDK Manager**: https://developer.garmin.com/connect-iq/sdk/
2. В SDK Manager установите Connect IQ SDK ≥ 7.x и device profile **Epix Gen 2**.
3. Установите Java JDK 21:
   ```powershell
   winget install Microsoft.OpenJDK.21
   ```
4. Сгенерируйте developer key (один раз):
   ```bash
   openssl genrsa -out developer_key.pem 4096
   openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem -out developer_key -nocrypt
   ```
   Положите `developer_key` в корень проекта (он в `.gitignore`).
5. В VS Code установите расширение **Monkey C** (Garmin).

## Сборка (PowerShell)

```powershell
.\build.ps1                  # debug для epix2
.\build.ps1 -Device fenix7   # другая платформа
.\build.ps1 -Release         # release .iq для Connect IQ Store
.\build.ps1 -Test            # unit-тесты

.\run.ps1                    # запустить симулятор и загрузить prg
.\run.ps1 -Test              # запустить тесты в симуляторе
```

## Установка на часы

1. Соберите release: `.\build.ps1 -Release` → получаете `bin\namaz.iq`.
2. Подключите часы по USB, скопируйте `bin\namaz.prg` (debug) в `GARMIN/APPS/`.
3. Для публикации в Connect IQ Store загружайте `.iq` через https://apps.garmin.com/.

## Настройки

На часах: кнопка Menu (долгое нажатие UP) → **Баптаулар / Настройки**.
Через Connect Mobile: Garmin Connect → My Watch → Connect IQ Apps → Namaz KZ.

| Параметр | Описание |
|---|---|
| Аср | Стандарт / Ханафи |
| Қала / Город | Auto (GPS) / 16 городов Казахстана |
| Алдын-ала: Таң | предуведомление перед Фаджром, 0 / 5 / 10 / 15 мин |
| Алдын-ала: басқа | предуведомление перед остальными намазами |
| Әдіс / Метод | один из 10 методов расчёта |
| Хабарландыру | вибрация вкл / выкл |
| Дірілдеу | паттерн вибрации |
| Тақырып / Тема | Қола / Жалбыз / Аспан / Моно |
| Құбыла | компас на Каабу |
| Тіл / Язык | Auto / қазақша / русский / english |
| Түзетулер | offset ±9 мин на каждый намаз |

```
  GlanceView.mc          glance

  Settings.mc            чтение Properties
  SettingsMenu.mc        меню настроек на часах (Menu2)
  BackgroundService.mc   фоновый сервис
resources/     strings (en/ru/kk), settings, drawables
tests/         unit-тесты (расчёт, хиджра, локация, города, нотификации, форматирование)
```

## Известные ограничения

- Таблица Umm al-Qura заканчивается в июне 2049; дальше ±1 день.
- Названия методов расчёта в настройках Connect Mobile не переводятся (имена собственные).
- Umm al-Qura: граница Рамадана определяется по таблице, а не по фактическому
  наблюдению луны в Саудовской Аравии.
