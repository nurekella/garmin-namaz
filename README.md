# Namaz — Garmin Connect IQ

Расчёт времени намаза для Garmin Epix Gen 2 по методике **ҚМДБ (ДУМК)**.
Работает оффлайн, локально по GPS, присылает уведомление о намазе.

Языки: **қазақша / русский / english** (выбирается по системному языку часов).

## Возможности

- 5 ежедневных намазов + восход (Таң, Күн, Бесін, Екінді, Ақшам, Құптан)
- Расчёт без интернета по GPS; **совпадает с официальными таблицами ҚМДБ** (см. «Точность»), в том числе на севере летом
- Название ближайшего города по GPS; ручной выбор из 89 городов Казахстана
- Экраны: главный (намазы + «через …»), обратный отсчёт (с остатком времени текущего намаза), 7 дней (Фаджр / Магриб); по желанию четвёртый — Духа и Тахаджуд
- Дизайн в стиле Material 3 на чёрном AMOLED: строки-«таблетки», ближайший намаз залит цветом, кольцо прогресса на экране отсчёта
- В пятницу «Бесін» — «Жұма»; под датой строка о празднике или о сунна-посте («Ертең ораза: Ақ күндер»)
- Напоминания: вечером перед сунна-постом (пн, чт, белые дни, Арафа, Ашура, Шәууал) и праздником (в т. ч. священные ночи); в пятницу за 60 мин до Зухра
- Уведомление в момент намаза (системное, часы вибрируют по своим настройкам уведомлений), предуведомление 5/10/15 мин и **предупреждение за 10/20/30 мин до конца времени Фаджра (восход) и Аср (закат)**; пункт «Проверить уведомление» присылает тестовое через 5 мин
- **Режим Рамадана**: включается сам в месяце Рамадан — отсчёт до ифтара и до конца сухура на экранах и в виджете
- Хиджра по календарю Умм аль-Кура (таблица 1440–1500 г.х.) с поправкой ±2 дня под объявление ҚМДБ
- Следующий намаз можно вывести на циферблат: в настройках циферблата выберите поле «Namaz»
- Виджет со следующим намазом и оставшимся временем
- Ханафи / стандартный мазхаб для Аср (по умолчанию Ханафи), 10 методов расчёта, поправки ±9 мин на каждый намаз
- Все настройки есть и на самих часах, и в Garmin Connect
- True-black AMOLED, три цвета акцента

## Точность

Модель ҚМДБ восстановлена по официальным таблицам api.muftyat.kz для 36 населённых пунктов на каждый день 2026 года:
Фаджр — 15,0° без поправок; Иша симметрична Фаджру (Иша − Магриб = Восход − Фаджр); поправки Зухр/Восход/Магриб/Аср
+3/−2/+2/+3 мин южнее 48° с.ш. и +5/−4/+4/+5 мин от 48° с.ш.; сумерки не длиннее 24,2 % ночи (так ҚМДБ считает летом на севере).
Средняя ошибка меньше минуты по каждому времени, худший промах Фаджра/Иши 3,3 мин. Эталон зашит в
`tests/OfficialTablesTest.mc`.

## Целевые устройства

- **Главное:** Garmin Epix Gen 2 (416×416 AMOLED, круглый)
- Совместимо: Fenix 7 / 7 Pro / 7X, Epix Pro, Forerunner 965

## Установка SDK (для разработки)

1. Скачайте **Connect IQ SDK Manager**: https://developer.garmin.com/connect-iq/sdk/
2. В SDK Manager установите Connect IQ SDK ≥ 9.1.0 и device profile **Epix Gen 2**.
3. Установите Java JDK 21:
   ```powershell
   winget install Microsoft.OpenJDK.21
   ```
4. Сгенерируйте developer key (один раз):
   ```bash
   openssl genrsa -out developer_key.pem 4096
   openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem -out developer_key -nocrypt
   ```
   Положите `developer_key` в корень проекта (он в `.gitignore`).
5. В VS Code установите расширение **Monkey C** (Garmin).

## Сборка (PowerShell)

```powershell
.\build.ps1                  # debug для epix2
.\build.ps1 -Device fenix7   # другая платформа
.\build.ps1 -Release         # release .iq для Connect IQ Store
.\build.ps1 -Test            # unit-тесты

.\run.ps1                    # запустить симулятор и загрузить prg
.\run.ps1 -Test              # запустить тесты в симуляторе
```

## Установка на часы

1. Соберите release: `.\build.ps1 -Release` → получаете `bin\namaz.iq`.
2. Подключите часы по USB, скопируйте `namaz.prg` (debug) в `GARMIN/APPS/`.
3. Для публикации в Connect IQ Store загружайте `.iq` через
   https://apps.garmin.com/.

## Структура

```
source/
  calc/        астрономия и расчёт намазов (DumkMethod, SolarMath, PrayerCalculator, HijriDate, Fasting, Occasions)
  location/    GPS и кеш локации (LocationProvider), города (Cities — 16 крупных, CityIndex — остальные)
  notify/      уведомления + scheduling (PrayerNotifier), данные для циферблата (FaceData)
  ui/          темы и локализованные имена (Theme, PrayerNames)
  utils/       вспомогательные (TimeFormatter, Storage)
  NamazApp.mc, CardView.mc (экраны + CardDelegate), GlanceView.mc, BackgroundService.mc
resources/     strings (en/ru/kk), settings, menus, drawables
tests/         113 unit-тестов
```

## Известные ограничения

- Glance и фоновый сервис показывают строки на английском (Rez недоступен в их
  бинарниках) — локализация glance запланирована на v1.1.
- Хиджри-дата может отличаться от Umm al-Qura на ±1 день в граничные дни месяца.
- Высокие широты (> 48°): используется angle-based fallback.
